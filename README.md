# Nikhil Tiwari — Portfolio

Next.js 16 (App Router) · Tailwind CSS v4 · HugeIcons · next-themes · Geist fonts

## Run
```bash
npm install
cp .env.example .env.local   # set NEXT_PUBLIC_SITE_URL (and optionally NEXT_PUBLIC_EMAIL)
npm run dev
```

## Edit content
All text, projects, experience and links live in `lib/site.ts`.

## Deploy
Push to GitHub and import the repo in Vercel. Set `NEXT_PUBLIC_SITE_URL` to your final domain.
